## 4. Style guidelines

### 4.1 Palette (`src/app/globals.css` → `:root`)

| Token | Hex | Use |
| --- | --- | --- |
| `--cream` | `#F3E3D0` | Page background, cream text on dark surfaces |
| `--terracotta` | `#B55A2A` | Brand accents, **large** primary CTA backgrounds only |
| `--terracotta-deep` | `#8C3F1C` | Small text, chips, hover states, CTA band background |
| `--espresso` | `#3B2313` | Primary text, dark inverse surfaces |
| `--ochre` | `#D49A3A` | Badges, lines, focus ring, non-text decoration |
| `--red` | `#A6261E` | Reserved accent |
| `--sage` | `#C7CEBE` | Alternate surface, original logo background |

Semantic tokens: `--surface-page`, `--surface-alt`, `--surface-inverse`, `--text-primary`, `--text-on-dark`, `--focus-ring`, `--border-subtle`.

### 4.2 Typography

- Display: Fraunces, weight 600/700, negative letter-spacing, used for `h1`–`h3` and the wordmark.
- Body: Plus Jakarta Sans, 400/500/600/700, 16px base, line-height 1.6.
- Craft notes: Courier Prime for the handmade/process voice.
- Fluid scale: `--text-display` `clamp(2.5rem, 9vw, 5rem)`, `--text-h2` `clamp(2rem, 6.5vw, 3.25rem)`, `--text-h3` `clamp(1.5rem, 4vw, 2rem)`, `--text-lead` `clamp(1.125rem, 3.2vw, 1.375rem)`.
- Utility classes: `.h1`, `.h2`, `.h3`, `.lead`, `.body-copy`, `.eyebrow`, `.craft-note`.

### 4.3 Layout and rhythm

- `.wrap` → `min(100% - 2×gutter, 1200px)`; gutter 20px mobile / 32px from 768px.
- `.section` / `.section--tight` → vertical padding 64px/96px (reduced on tight).
- Radii: 4px (small), 12px (cards), 24px (large), 999px (pills/buttons).
- Motion: `--duration: 200ms`; always respect `prefers-reduced-motion`.
- `<html>` has `data-scroll-behavior="smooth"` — required by Next.js 16 when using global smooth scrolling, otherwise route transitions log a warning.

### 4.4 Buttons and interactive rules

- `.btn` has `min-height: 52px` (`.btn--sm`: 44px), pill shape, bold label, 2px border.
- Variants: `.btn--primary`, `.btn--secondary`, `.btn--light`, `.btn--outline-light`, `.btn--block`, `.btn--sm`.
- **Every interactive target must be ≥44px tall**: nav links, footer links, filter chips, inputs, icon buttons.
- `:focus-visible` → 3px ochre outline with 3px offset. Never remove it.
- Mobile drawer: `role="dialog"`, focus trap, Escape to close, body scroll lock via `.mobile-menu-open`.

### 4.5 Contrast rules (both fixes are mandatory)

1. **Fix A** — small text/chips/hover states use `--terracotta-deep` (`#8C3F1C`): 5.88:1 on cream, 4.57:1 on sage. `.eyebrow`, `.craft-note`, `.filter-chip`, small primary buttons, and the whole `.cta-band` use it. The `.booking .field-hint` uses ochre on espresso.
2. **Fix B** — primary CTAs keep brand `--terracotta` `#B55A2A` **only** with a cream label at `19px / 700` (`--text-cta`), which passes AA as large text (3.75:1). Do not shrink that label or put small cream text on brand terracotta.

Never introduce small cream text on `#B55A2A` or small ochre text on cream.

### 4.6 Copy and brand voice

- Official name: **Kartagena Afrudas** everywhere (copy, metadata, alt text). `AFRUDOS` appears only inside the logo artwork.
- Keep Spanish orthography with accents: `raíz`, `diseño`, `conexión`, `técnicas`, `Macramé`, `Asesorías`, `Envíos`, `dedicación`, `Escríbenos`, `Línea Creación`, `Memoria y Raíz`.
- Voice: warm, ancestral, handmade, direct. Short invitations to write or book; avoid inventing product names or claims.
- Social display labels are legacy on purpose: Instagram `@Kartagenaafrudas`, TikTok `Kartagina_afrudas`; URLs are `https://www.instagram.com/kartagenaafrudas/` and `https://www.tiktok.com/@kartagena_afrudas?lang=en`. WhatsApp display `3003230109` → `https://wa.me/573003230109`.
- Change copy in `src/lib/content.ts`, never hard-code it in components.

## 6. Asset pipeline and the logo fix

- Source: `logo/logo.png`, 894×959 RGBA with flat `#C8D2C0` background. `BG` in `scripts/prepare-assets.mjs` assumes that flat color; update it if new artwork has a different background.
- `npm run prepare:assets` regenerates everything. It removes the sage background by tolerance, crops the primary mark, and derives:
  - `ka-primary-on-sage_v1.*` — full lockup on the original sage.
  - `ka-primary-transparent_v1.*` — transparent lockup.
  - `ka-primary_mono-espresso_v1.*`, `ka-primary_mono-cream_v1.*` — single-ink lockups.
  - `ka-isotype-transparent_v2.*`, `ka-isotype_mono-espresso_v2.*`, `ka-isotype_mono-cream_v2.*` — the braided heart emblem **with built-in clear space**.
  - favicons, OG image, `src/app/icon.png`, `src/app/apple-icon.png`.
- **Why `v2`:** the emblem spans `x=12..875, y=95..958`. The first crop stopped at `y=688`, cutting about a third of the bottom; the second crop included the full heart but touched the edges of the 44px nav icon. The final crop extracts the full `864×864` bounds, scales to `600×600`, then adds `60px` transparent padding on all sides (`720×720`). Old `v1` isotypes were deleted to avoid stale references.
- Header/page/footer import the `v2` isotype explicitly. If an icon still looks clipped, bump the version again — this busts the browser/Next image cache. Never edit a generated file directly; change the script and re-run it.

Rendered verification: at a 390px viewport the `.brand-mark` is 44×44 with the mark at `4,3..39,40` — 3–4px of clear space on every side.

## 10. Common recipes

- **Change a label or link:** edit `src/lib/content.ts`; social + WhatsApp strings live in `BRAND`.
- **Change a color:** edit the token in `src/app/globals.css`; keep the contrast rules in §4.5.
- **Add a page:** create `src/app/<slug>/page.tsx`, add it to `NAV_LINKS`, reuse `PageHero`, `CtaBand`, `.wrap`/`.section`.
- **Change the logo:** replace `logo/logo.png`, update `BG` in `scripts/prepare-assets.mjs` if needed, run `npm run prepare:assets`, bump asset versions in components, rebuild.
- **Change the WhatsApp number:** update `whatsappInternational` in `src/lib/content.ts`; the builder in `src/lib/whatsapp.ts` handles the rest.
- **Troubleshooting:** stale images → bump the filename version and delete `.next`; dev server dead → `npm run dev`; port conflict → `npm run dev -- -p <port>`.
